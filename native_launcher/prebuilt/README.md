# Executáveis de referência

Binários da versão **1.5.13**, identificada no `VERSION` desta pasta, preservados para conferência do código e dos metadados. Não execute diretamente desta subpasta.

O build recompila os aplicativos a partir de `native_launcher/` e instala os executáveis na raiz do pacote. Baixe o [Setup oficial](../../releases/README.md) para usar o NexoFlow.

A versão de referência é independente da versão em preparação na raiz. A auditoria aceita esses metadados somente nesta subpasta; executáveis instalados na raiz precisam coincidir com a versão da distribuição. O workflow Windows recompila e verifica os EXEs da nova entrega.
