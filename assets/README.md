# Ícones e imagens

Recursos visuais dos aplicativos e do instalador. Cada aplicativo tem seu ícone, incorporado ao executável durante o empacotamento.

Os arquivos `NexoFlow_Noturno`, `NexoFlow_Planilha`, `NexoFlow_Recompra`, `NexoFlow_Weni` e `NexoFlow_Terminal` identificam os respectivos componentes. Veja os [launchers](../native_launcher/README.md).
