# Aplicação

Código Python das integrações Weni, FarmaLíder e Google Sheets, processamento de pedidos e geração das tabelas do Data Studio.

As entradas `run_*.py` iniciam as rotinas. Para o uso diário, prefira os executáveis ou [comandos](../comandos/README.md). Consulte o [guia de operação](../docs/Documentacao%20NexoFlow.md).
