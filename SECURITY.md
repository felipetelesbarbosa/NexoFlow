# Segurança

O NexoFlow é distribuído sem chaves de acesso, tokens de API, senhas ou credenciais.

Use suas próprias chaves e tokens. Configure os acessos à Weni, API FarmaLíder e Google para os segmentos FarmaLíder e Pets Líder seguindo o [guia de instalação](docs/README%20INSTALACAO.md).

Mantenha suas credenciais privadas. Não as compartilhe nem as publique no GitHub.
