# Meta Ads MCP local nas versões anteriores

O NexoFlow Windows 1.5.42 retira o servidor Meta Ads MCP local e os auxiliares de instalação do Codex CLI. Para coletar métricas de anúncios no Analytics ou no Noturno, use a integração Meta nativa e preserve o JSON privado existente em `credentials/mcp/meta_ads_credentials.json`. [Guia operacional da integração nativa](META%20ADS%20NATIVO.md).

Os detalhes técnicos e os comandos das versões até 1.5.41 estão arquivados com a respectiva versão do projeto. [Especificação da versão 1.5.41](https://github.com/felipetelesbarbosa/NexoFlow/blob/v1.5.41/docs/META%20ADS%20MCP%20LOCAL.md).
