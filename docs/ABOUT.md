# Descrição do repositório

Texto para o campo About do GitHub:

> NexoFlow para Windows integra Weni, API FarmaLíder, Meta Ads, Google Sheets e Data Studio para FarmaLíder e Pets Líder. Contatos, pedidos e Recompra com auditoria e sincronização incremental. Novos segmentos por configuração. NexoFlow Hub é um projeto separado para cloud.

A integração usada na publicação pode atualizar código e releases, mas não possui permissão administrativa para alterar os metadados do repositório. Se o GitHub recusar a alteração do About, o proprietário pode aplicar o texto acima em Settings ou no botão de edição da descrição. Isso não interfere na instalação ou nas sincronizações.

O [planejamento do Hub](planejamento/README.md) permanece separado da [operação Windows](README%20INSTALACAO.md).
